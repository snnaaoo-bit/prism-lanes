# Prism Lanes

プロセカ風の遊び方をした、オリジナルの6レーン音ゲー（ブラウザ・HTML 1枚）。
キャラ・曲・絵はすべてオリジナル。曲は Web Audio でその場で作る。

- 公開ページ（非公開・本人だけ）: https://claude.ai/artifact/UL17FedTqQ1VWythXd27PQ
- 手元で遊ぶ: `index.html` をブラウザで開く

## 操作

| | キーボード | スマホ |
|---|---|---|
| レーン | `S` `D` `F` `J` `K` `L` | レーンをタッチ |
| フリック（ピンク） | `Space`（`↑` でも可） | レーンを上へはじく |
| 一時停止 | `Esc` | 左上のボタン |

## ノート

- 水色: タップ／黄色: 幅広（かかっているキーのどれでも）
- 緑: 長押し（終わりまで押したまま。終わる0.12秒前より後なら離してもよい）
- ピンク: フリック

## 判定

PERFECT ±50ms / GREAT ±100ms / GOOD ±150ms / それより外は MISS。
スコアは 100万点満点（PERFECT 1・GREAT 0.7・GOOD 0.4 の割合）。S 95万 / A 90万 / B 80万 / C 70万。

## 中身

- `SONGS`: 曲（BPM・調・和音の進行・乱数の種）。種が同じなら毎回同じ曲と譜面
- `DIFFS`: 難易度ごとの譜面の作り方（最小間隔・長押しの割合・同時押し・幅・ドラムから足す割合）
- 譜面はメロディ＋ドラムから自動で作る。レーンは音の高さで決める
- 時刻はすべて音の時計（`AudioContext.currentTime`）が基準。`settings.offset` で補正
- 記録と設定は localStorage（使えない環境でも止まらない）

変更履歴は `CHANGELOG.md`。
